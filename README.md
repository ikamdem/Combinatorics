# Combinatorics
Python project to compute and explain combinatorial formulas for any draw scenario.

This interactive Python project automatically calculates the total number of combinations, arrangements, or permutations according to user-defined parameters (number of items, with or without repetition, order matters or not, etc.).
It also displays the winning probability for a single random draw and specifies the exact formula used.
The tool is perfect for learning combinatorics, checking your own calculations, or illustrating probability concepts (lottery, cards, PIN codes, etc.).
